Convention collective : identifier celle qui s'applique réellement

Article rédigé par la rédaction Lexovance

La réponse courte

La convention collective s'attache à l'entreprise par son activité principale — reflétée par le code APE/NAF — puis au salarié par le rattachement de son poste à une classification. L'erreur a des conséquences concrètes : coefficients, salaires minima, préavis [S2], indemnités, primes conventionnelles.

Le contrat qui dit « convention de la métallurgie » alors que l'entreprise relève de la Syntec n'y change rien : c'est le rattachement réel qui compte, pas la mention. La vérification : code APE de l'entreprise → convention correspondante → classification du poste → comparaison à la fiche de poste réelle [S1].

Ce qui peut changer la réponse

  • Une entreprise multi-activités peut relever de plusieurs conventions selon les établissements.
  • Le code APE se corrige : une erreur d'INSEE ne fait pas la règle si l'activité réelle est ailleurs.
  • Les accords d'entreprise peuvent déroger dans les matières permises : vérifier la hiérarchie des textes.

Cas pratique (fictif)

Entreprise fictive déclarée « conseil » mais exerçant une activité mixte : le code APE renvoie à une convention dont le classification change le coefficient du salarié. La requalification d'un poste change minima et préavis — trois années de paie sont recalculées.

L'étape à reproduire

Pour chaque contrat : code APE → convention → classification du poste (coefficient, intitulé). Trois vérifications, trois sources d'erreur fréquente — et trois corrections qui valent des rappels ou des sécurisations.

Ce que montre Lexovance

*Exemple illustratif sur données fictives.* Sur le contrat fictif, Lexovance confronte la convention déclarée à l'activité de l'entreprise et signale l'écart de classification.
